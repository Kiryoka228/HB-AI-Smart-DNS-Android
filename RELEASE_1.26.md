# HB AI Smart DNS Android 1.26.0 (beta)

**Ключевое улучшение:** автоподбор HTTPS-маршрутов ChatGPT и Gemini непосредственно из сети Android. Поддерживаются Comss.one, GeoHide EU, MagicDNS (с резервированием) и Xbox DNS (без переписывания его назначения).

Автопроверка перебирает DNS A-адреса, устанавливает защищённое соединение с SNI и проверяет сертификат; недоступные адреса исключаются на короткое время, при необходимости применяется ответ резервного Smart DNS. Исправлены случаи, когда часть IP-адресов GeoHide не отвечает на 443, хотя остальные работают.

Добавлены счётчики проверенных HTTPS-путей и резервных переключений. Никаких постоянных жёстко заданных IP-адресов из результатов GitHub Actions в APK нет.

**Ограничения:** APK ещё не проверен на реальном Android. DNS не исправляет HTTP 403 от сервера, географические ограничения, CAPTCHA, доступ к аккаунту, приложение с собственным DoH/DoT, QUIC или необходимость полного VPN-подключения. HTTP 302 может быть обычным переходом к авторизации. Проверка HTTPS 2xx/3xx не доказывает, что вход в ChatGPT/Gemini работает.

**Подпись:** отладочная подпись GitHub Actions может отличаться от APK предыдущего релиза. Если установка поверх не удалась — предварительно сохраните настройки и удалите прежнюю версию.
