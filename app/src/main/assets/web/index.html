Системный DNS на Android

DNS-VPN

В APK встроен собственный DNS-движок. Если установлен и разрешён root (Magisk/KernelSU), применяется системный перехват DNS. Без root приложение предлагает локальный DNS-VPN через официальный механизм Android; отдельный Termux не требуется.

Private DNS: неизвестно

Счётчик доказывает только прохождение обычного DNS. Защищённый DNS, региональные ограничения по IP и вход в аккаунт этим способом не обходятся. В приложениях может понадобиться отдельно разрешённое сетевое подключение.

Настройка без root

В режиме без root нажмите «Включить» и разрешите Android локальную VPN-службу. Она будет обслуживать системные DNS-запросы через выбранного провайдера как для Wi-Fi, так и для мобильной сети. Если используется другой VPN, они могут конфликтовать; приложения с собственным DoH могут обходить системный DNS.

Ограничения режима root

В root-режиме используются su, iptables NAT и локальный DNS-прокси, а режим Private DNS временно отключается с сохранением исходной настройки. Для IPv6 ip6tables используется там, где поддерживается. Другие VPN, DoH/DoT внутри приложений и ограничения SELinux могут обходить этот метод. При отключении программа удаляет только собственные правила; дополнительно работает watchdog для аварийного отката.
